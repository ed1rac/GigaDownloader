## ✨ Recursos Principais

- 🎥 **Download em Alta Definição**: Suporta resoluções 720p, 1080p, 2K e 4K (de acordo com a disponibilidade na fonte).
- 🎵 **Extração Direta de Áudio**: Converte automaticamente vídeos para MP3 com taxa de bits otimizada.
- 🌐 **Milhares de Sites Suportados**: Total compatibilidade com YouTube, Instagram, TikTok, Twitter/X, Reddit, Twitch, Vimeo, Facebook e centenas de outros portais.
- 📊 **Progresso em Tempo Real**: Barra visual com porcentagem, velocidade de transferência e tempo estimado.
- 📦 **Sem Dependências**: Binários portáteis independentes compilados via GitHub Actions para Windows, Linux e macOS.

## 🚀 Como Executar

### Opção 1: Baixar os Executáveis Prontos (Recomendado)
Acesse a [**Aba de Releases**](https://github.com/ed1rac/GigaDownloader/releases) e baixe a versão compatível com seu sistema operacional (não requer instalação prévia do Python).

### Opção 2: Executar via Código-Fonte (Python)
```bash
# 1. Clonar o repositório
git clone https://github.com/ed1rac/GigaDownloader.git
cd GigaDownloader

# 2. Instalar dependências
pip install -r requirements.txt

# 3. Executar o aplicativo
python ytdownloader.py
```
